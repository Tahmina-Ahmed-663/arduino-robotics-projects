# Arduino Robotics Projects

A collection of two Arduino-based robotics projects completed through
practical group work during the NextGen Automation & Embedded Systems
workshop in February 2025.

The two-day workshop was conducted by the IEEE East West University
Student Branch and supported by Robo Tech Valley.

## 1. Obstacle-Avoiding Robot

An Arduino-based mobile robot that uses an HC-SR04 ultrasonic sensor to
measure the distance ahead. The program controls the DC motors according
to the measured distance, allowing the robot to move forward when the
path is clear and reverse and turn when an obstacle is detected within
the defined threshold.

![Obstacle-Avoiding
Robot](obstacle-avoiding-robot/obstacle-avoiding-robot.jpg)

**Key components:** Arduino-compatible board, HC-SR04 ultrasonic sensor,
motor driver, and DC motors.

**Technical focus:** Ultrasonic distance measurement, motor direction
control, and PWM-based speed control.

## 2. Voice-Controlled Robot Car

An Arduino-based robot car control system that responds to serial text
commands for movement and LED operation. The program processes commands
such as forward, reverse, left, right, and stop, then controls the motor
outputs accordingly.

![Voice-Controlled Robot
Car](voice-controlled-robot-car/voice-controlled-robot-car.jpg)

**Key components:** Arduino-compatible board, motor driver, DC motors,
and LED.

**Technical focus:** Serial communication, command processing, and motor
control.
